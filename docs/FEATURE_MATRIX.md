# Ma trận chức năng OmniflowAI

| Phân hệ | Khả năng hoạt động trong bản HTML | Tích hợp production |
|---|---|---|
| Trang giới thiệu | Có hero, mô tả tính năng, câu hỏi thường gặp, CTA | Có thể bổ sung form đăng ký và tracking hợp pháp |
| Dashboard | KPI, bảng, biểu đồ dựa trên dữ liệu mẫu | DB và analytics pipeline |
| Inbox | Tìm kiếm, lọc, đọc, soạn gửi cục bộ, đánh dấu hoàn tất, đổi nhãn, tạo đơn | OAuth, webhook, quyền nhắn tin chính thức |
| AI | Bật/tắt, thiết lập giọng điệu, FAQ, gợi ý theo quy tắc | Backend AI, RAG, API, quản trị dữ liệu |
| Livestream | Start/stop mô phỏng, nhận diện từ khóa, thêm bình luận | Streaming event/webhook thật |
| Sản phẩm | Tạo/sửa/xóa khi chưa có đơn, tìm kiếm, CSV, tồn kho | DB nhiều người dùng, audit log |
| Đơn hàng | Tạo, cập nhật trạng thái, chi tiết, xuất CSV, cập nhật tồn khi tạo mới | Thanh toán, vận chuyển, giao dịch nhất quán |
| CRM | Tạo/sửa, lọc theo kênh, lịch sử đơn, CSV | Mã hóa/đồng ý xử lý dữ liệu, phân quyền |
| Marketing | Tạo, bật/tắt, lọc chiến dịch | API gửi thật, giới hạn, consent |
| Báo cáo | Tổng tiền, đơn, sản phẩm bán chạy, kênh và doanh thu theo ngày | Data warehouse/BI nếu cần |
| Nhân sự | Thêm/xóa vai trò hiển thị | Auth/RBAC backend |
| Cài đặt | Lưu tên cửa hàng, cấu hình, sao lưu JSON, reset | Quản lý tích hợp/API security |

Những tính năng cần kết nối không được mô tả là đã vận hành thật.
